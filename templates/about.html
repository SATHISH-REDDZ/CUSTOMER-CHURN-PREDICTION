About Customer Churn Prediction System

An end-to-end Machine Learning web application designed to identify telecom subscribers at risk of churn, analyze customer behavior drivers, and provide actionable retention interventions.

Problem Statement

Telecom service providers face severe revenue loss when customers cancel their subscriptions. Manually auditing thousands of account profiles to identify dissatisfied or churn-prone customers is inefficient and error-prone. This application addresses that problem by automatically evaluating subscription features, computing churn probability, and categorizing account risk before cancellation occurs.

Preprocessing & ML Workflow

The 7,043 Telco customer records are processed through a Scikit-Learn ColumnTransformer. Numerical attributes (SeniorCitizen, tenure, MonthlyCharges, TotalCharges) are normalized using StandardScaler. Categorical features are encoded using OneHotEncoder. Models are evaluated using 80/20 train-test split, and the best-performing model is selected via ROC-AUC.

Evaluated Machine Learning Algorithms

Logistic Regression

Baseline statistical classification algorithm estimating probability using sigmoid activation function.

Decision Tree

Tree-structured model splitting data on feature conditions to establish decision boundaries.

Random Forest

Ensemble of randomized decision trees reducing variance and providing feature importance rankings.

Gradient Boosting (Selected)

Sequential boosting ensemble optimizing residual errors. Achieved highest ROC-AUC score.
